## Summary

Brute It focused on discovering hidden web resources, brute-forcing login credentials, cracking password hashes, and escalating privileges to obtain root access on a Linux machine.

## Tools Used

- Nmap

---

## Workflow

1. Performed reconnaissance using **Nmap**.
2. Enumerated web directories with **Gobuster**.
3. Brute-forced login credentials using **Hydra**.
4. Logged into the target via **SSH**.
5. Cracked password hashes with **John the Ripper**.
6. Enumerated sudo permissions and escalated privileges to root.

---

## Key Takeaways

- Weak passwords are vulnerable to brute-force attacks.
- Proper enumeration reveals multiple attack paths.
- Misconfigured sudo permissions can lead to privilege escalation.
- Strong password policies and least-privilege access are essential.
